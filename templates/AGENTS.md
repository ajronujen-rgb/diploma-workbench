# Правила проекта диплома

- Диплом остаётся работой автора.
- Не выдумывай факты, библиографию, цитаты, страницы, источники, данные и результаты исследования.
- Отделяй источник, пересказ, данные и вывод автора.
- При нехватке данных спрашивай или помечай для проверки.
- Не изменяй исходные материалы.
- Не повышай человеческие статусы автоматически и не изменяй замороженные материалы без разрешения.
- Соблюдай методичку, замечания руководителя, паспорт исследования и журнал решений.
- Сохраняй промежуточные результаты, состояние проекта и историю возвратов.
- Береги лимит: длительную содержательную работу передавай через CHATGPT_HANDOFF.
- Работу можно продолжать без Codex через CHATGPT_START.md и inbox.
