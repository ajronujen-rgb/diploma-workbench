# Продолжение без Codex

Передайте обычному ChatGPT только: тему, текущую задачу из `PROJECT_STATE.md`, паспорт исследования, относящиеся к задаче решения, разрешённые источники/выдержки и собственные материалы автора. Попросите его вернуть результат строго в формате `CODEX_RETURN` из протокола скилла. Сохраните возврат в `inbox/pending/` или вставьте в Codex после восстановления доступа.
