# Чеклист оформления итогового диплома

Статус: временная ГОСТ-база до получения методички вуза.

- [ ] Получена и проверена методичка вуза/кафедры. Если нет, оставьте этот статус и используйте временную базу.
- [ ] Титульный лист оформлен по доступному шаблону вуза; если шаблона нет — помечен для последующей замены.
- [ ] В содержании совпадают названия разделов и номера страниц.
- [ ] Есть введение, основная часть, заключение, список источников; приложения добавлены при наличии.
- [ ] Нумерация страниц и заголовков единообразна.
- [ ] Формат страницы A4 и односторонняя печать проверены.
- [ ] Шрифт, интервал, абзацный отступ и поля проверены по временному профилю либо методичке.
- [ ] Список источников проверен по ГОСТ Р 7.0.100-2018.
- [ ] Ссылки/сноски проверены по ГОСТ Р 7.0.5-2008 и единообразны.
- [ ] Русскоязычный финальный текст проверен на избыточную англоязычную терминологию; необходимые оригиналы и технические обозначения сохранены осознанно.
- [ ] Итоговый DOCX или PDF визуально проверен после рендеринга.

См. `references/gost-baseline.md` в skill. При наличии методички её требования имеют приоритет.
