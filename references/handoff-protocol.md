# Протокол ChatGPT ↔ Codex

## CHATGPT_HANDOFF

```text
=== CHATGPT_HANDOFF ===
Проект: <кратко>
Текущий этап: <этап>
Задача сессии: <одна конкретная задача>
Утверждённый контекст: <только релевантные решения и паспорт>
Разрешённые источники и материалы: <ID, точные выдержки при необходимости>
Ограничения: <методичка, статусы, запреты>

Работай только с предоставленным контекстом и разрешёнными источниками. Не выдумывай факты, библиографию, страницы или цитаты. Отличай сведения источника, пересказ, данные и вывод автора. Не меняй утверждённые решения молча. При нехватке информации спрашивай автора. Используй его мысли, тезисы, ответы, голосовые и сырой текст как содержательную основу; не подменяй автора. По завершении подготовь CODEX_RETURN.
=== END CHATGPT_HANDOFF ===
```

Не добавляй автоматически весь диплом, методичку, базу источников или журнал.

## CODEX_RETURN

```text
=== CODEX_RETURN ===
Задача:
Результат:
Принятые решения:
Текст для сохранения:
Использованные источники и их ID:
Новые фактические утверждения:
Утверждения, требующие проверки:
Нерешённые вопросы:
Предлагаемые изменения файлов:
Автор подтвердил содержание: ДА / НЕТ
Фактическая проверка: ПРОЙДЕНА / ТРЕБУЕТСЯ
Статус материала:
=== END CODEX_RETURN ===
```

При приёме проверь границы блока, все поля и ссылки на ID. Не считай возврат фактической истиной. Не повышай статус самостоятельно. Если затрагивается `ЗАМОРОЖЕНО`, согласованный материал или решение более высокого приоритета — не интегрируй содержательные изменения без решения человека.
