# Рабочий цикл

1. Codex читает компактное состояние и классифицирует задачу.
2. Для A/B обновляет локальные файлы пакетно, не затрагивая оригиналы.
3. Для C формирует `CHATGPT_HANDOFF`; обычный ChatGPT работает с автором и выдаёт `CODEX_RETURN`.
4. Codex принимает возврат из чата или `inbox/pending`, валидирует, ищет конфликт с паспортом, решениями, статусами и замороженными материалами.
5. Допустимое интегрирует в производные файлы; конфликтное переносит в `inbox/needs-decision` и объясняет, что требуется решение человека.
6. Codex сохраняет историю возврата, обновляет `PROJECT_STATE.md`, журнал работы и при необходимости журнал решений.
7. По завершении смысловой части запускает конвейер: Чуковский → Аграновский → Слопотрон → Розенталь → Мильчин.

После конвейера человек сверяет источник, страницу, дословность цитаты, выводы из данных, авторство собственного вывода и методичку.
