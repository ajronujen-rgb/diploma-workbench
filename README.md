# Diploma Workbench

Репозиторий содержит только скилл. Никогда не помещайте в него папку диплома и не инициализируйте Git внутри проекта диплома.

## Перенос и подключение

1. Клонируйте или скачайте приватный репозиторий на компьютер автора.
2. Скопируйте папку `diploma-workbench` в `%USERPROFILE%\.codex\skills\diploma-workbench` (или в каталог, заданный переменной `CODEX_HOME`), затем начните новый сеанс Codex.
3. Внутри папки скилла запустите `powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1 -ProjectPath "<папка_диплома>"`, подставив отдельную локальную папку для диплома.
4. Скилл зависит от `chukovsky`, `agranovsky`, `slopotron`, `rozental`, `milchin` и `vinogradov`. Чтобы явно установить отсутствующие зависимости, добавьте `-InstallDependencies`. Без этого флага bootstrap только сообщит их статус.

## Новый или существующий проект

Для нового проекта укажите новую папку. Для существующего — его текущую папку: bootstrap создаст только отсутствующие служебные элементы и выведет сообщения о сохранённых файлах. Он не переписывает диплом, источники, данные или пользовательские настройки.

## Обновление

Обновляйте только репозиторий скилла. Затем перезапустите Codex или начните новый сеанс. Локальный проект диплома находится в другой папке и обновлением скилла не затрагивается. После обновления можно запустить `scripts/audit-project.ps1 -ProjectPath "<папка_диплома>"` для проверки структуры.

## Проверка зависимостей

После команды с `-InstallDependencies` bootstrap повторно напечатает статус всех шести skills. Успешный результат — для каждого указано `УСТАНОВЛЕН`. Если хотя бы один остаётся `ОТСУТСТВУЕТ`, скрипт завершается с понятным именем навыка: проверьте сеть, Python и доступ к соответствующему публичному репозиторию `beaverbeard`. Список точных источников есть в `references/dependencies.md`.
